==================================================================
ROADMAP - HABIT TRACKER API (NestJS + PostgreSQL)
==================================================================

STACK DEFINIDA
------------------------------------------------------------------
- Runtime: Node.js 24 (LTS)
- Gerenciador de pacotes: pnpm
- Framework: NestJS (ESM)
- Banco de dados: PostgreSQL (via Docker)
- ORM: TypeORM
- Autenticação: JWT (access token curto + refresh token)
- Hash de senha: bcrypt
- Validação: class-validator + class-transformer
- Documentação: Swagger/OpenAPI
- Testes: Jest (integração, já vem com o Nest)
- Deploy: Docker + Render/Railway/Fly.io

FASE 2 - MODELO DE DADOS (ENTITIES)
==================================================================
[ ] Entity User

[ ] Entity Habit

    - name

    - target_count
    - created_at

[ ] Entity HabitLog
    - id (UUID)
    - habit_id (FK -> Habit)

[ ] Definir relacionamentos no TypeORM (@OneToMany / @ManyToOne)
